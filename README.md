# 3D Minecraft Web Edition (MVP)

HTML5 / CSS3 / JavaScript (Three.js) で作られたブラウザ上で動作する3DマインクラフトMVPです。
外部テクスチャ画像や音声ファイルへの依存がなく、純粋なWeb技術（プロシージャルテクスチャ + Web Audio APIシンセシス）で高速・軽量に動作します。

## 🎮 主な機能

- **ボクセルワールド生成**:
  - 起伏のある自然な地形（草、土、石）
  - オークの木（幹、葉）
  - スポーン地点のレンガ拠点（窓、本棚、グロウストーン照明）
- **高速描画エンジン**:
  - 面カリング（隠面消去）による頂点削減
  - 4x4プロシージャル・テクスチャアトラス
  - 不透明／半透明（ガラス・葉）の2パス描画
- **物理演算 & 操作**:
  - 3軸分離AABB衝突判定（壁抜け・床抜け防止、滑らかな登坂）
  - 重力、歩行、ジャンプ、ダッシュ、クリエイティブ飛行モード（Fly）
- **インタラクション**:
  - レイキャスティングによる視線先ブロックのハイライト枠表示
  - **左クリック**: ブロック破壊 ＋ 破壊パーティクルエフェクト ＋ 効果音
  - **右クリック**: ブロック設置 ＋ 設置効果音
  - **1〜9キー / ホイール**: 9枠ホットバーによるブロック切り替え
- **サウンド（Web Audio API 完全内蔵）**:
  - ブロック破壊音、ブロック設置音、ジャンプ音、足音
- **環境 & 演出**:
  - リアルタイム昼夜サイクル（空・フォグ・太陽光の変化）
  - FPSカウンタ、XYZ座標、方角表示HUD
- **モバイル対応**:
  - タッチスクリーン用バーチャルスティック＆アクションボタン

## 🕹️ 操作方法 (PC)

| 操作 | キー / マウス |
| :--- | :--- |
| **移動** | `W`, `A`, `S`, `D` または矢印キー |
| **視点操作** | マウス（画面中央で照準） |
| **ジャンプ** | `Space` |
| **ダッシュ / 急降下** | `Shift` |
| **ブロック破壊** | **左クリック** |
| **ブロック設置** | **右クリック** |
| **ブロック切替** | `1` 〜 `9` または **マウスホイール** |
| **飛行モード切替** | `F` |
| **昼夜・時刻切替** | `T` |
| **一時停止 / 解除** | `Esc` |

## 🚀 デプロイ (GitHub Pages)

リポジトリの `main` ブランチにプッシュされると、GitHub Actions（`.github/workflows/deploy.yml`）が自動実行され、GitHub Pagesへデプロイされます。
